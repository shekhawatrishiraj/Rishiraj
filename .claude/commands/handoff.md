# Pre-Handoff Checklist

Run PRE-HANDOFF mode (Checklist Enforcer) before reviews or engineering handoff.

---

Set operating mode to **PRE-HANDOFF**. Verify completeness:

- [ ] **Edge cases**: What breaks? Empty/error/overloaded states? (3+ non-obvious)
- [ ] **Tradeoffs explicit**: What user needs NOT solved, why?
- [ ] **Constraints honest**: Accepted vs. challenged? Any designed around that should've been pushed?
- [ ] **5Ws answered**: Who, what problem, why now, why this solution?
- [ ] **References cited**: Prior art? Learnings?
- [ ] **Second-order consequences**: Unintended behaviors incentivized?

Start by asking: What are you preparing for handoff?
